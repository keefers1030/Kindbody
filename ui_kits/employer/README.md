# UI kit — employer benefits

Standalone mount of `EmployerScreen` (the file lives in `../website/` because it shares the site chrome). Covers the B2B surface: the "Bringing Care Directly to Your Employees" hero, the three proof numbers from the brand boilerplate (121 employers, 3.1M lives, \$315M raised), the three-pillar value story, the coverage accordion, and press pull-quotes.

Numbers and claims are quoted from the 2024 brand guidelines boilerplate. They are dated — refresh them against current company figures before using this screen externally.
