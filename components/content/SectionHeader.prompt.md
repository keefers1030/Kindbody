One-line: opens every marketing section — eyebrow, Domaine headline, optional intro, optional trailing CTA.

```jsx
<SectionHeader eyebrow="Our services" title="A new generation of fertility care has arrived"
  intro="Fertility and family-building care in modern, tech-enabled clinics."
  action={<Button variant="outline">Services &amp; pricing</Button>} />
```

Default is left-aligned (the brand never centers paragraph copy — `align="center"` is for short headline-only cases). Use `tone="light"` on navy.
