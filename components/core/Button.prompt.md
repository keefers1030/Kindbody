One-line: the Kindbody call to action — a full-pill uppercase button; yellow is the primary CTA on light grounds, navy or outline-light on navy grounds.

```jsx
<Button variant="primary" size="lg" href="/scheduling">Get started</Button>
<Button variant="outline" iconRight="arrow-right">Services &amp; pricing</Button>
```

Variants: `primary` (yellow, navy label), `navy`, `outline`, `outline-light` (for navy/photo grounds), `ghost`. Sizes sm/md/lg. Hover darkens the fill or fills the outline — never an opacity fade. Renders an `<a>` automatically when `href` is set.
